## 1.デフォルトファームウェアについて 
>[!NOTE]
>**・マウス操作向けの割り当てです。トラックボールを動かすと自動でオートマウスレイヤーに切り替わり、どの状態でも左クリック・戻る・進むが使えます。**

### 1-1.キーマップ  

####  通常のキーマップ  

| キー | 割り当て |
|:-|:-|
| 0キー| Bluetooth接続先変更（1→2→3のトグル） |
| 1キー| 戻る（マウス戻るボタン / MB4）|
| 2キー| 左クリック |
| 3キー| スクロールON/OFFトグル（スクロールレイヤーへ） |
| 1キー + 2キー| 進む（マウス進むボタン / MB5） |
| 2キー + 3キー| 右クリック |
| 0キー + 3キー| 現在のBluetooth接続先情報を削除 |

### 1-2.オートマウスレイヤー  

>[!NOTE]
>**・トラックボールを動かしている間、自動で有効になります。**

####  オートマウスレイヤー中のキーマップ  

| キー | 割り当て |
|:-|:-|
| 0キー| Bluetooth接続先変更（1→2→3のトグル） |
| 1キー| 戻る（MB4）|
| 2キー| 左クリック |
| 3キー| スクロールON/OFFトグル |

### 1-3.スクロールレイヤー  

>[!NOTE]
>**・3キーで切り替え。有効中はトラックボールがスクロールホイールになります。もう一度3キーで解除します。**

####  スクロールレイヤー中のキーマップ  

| キー | 割り当て |
|:-|:-|
| 0キー| Bluetooth接続先変更（1→2→3のトグル） |
| 1キー| 戻る（MB4）|
| 2キー| 進む（MB5） |
| 3キー| スクロール解除（通常へ戻る） |
